   # Support Management System

   A support ticket system: customers open tickets and chat with staff;
   staff manage tickets by status and assignment.

   > Work in progress. A rewrite of my earlier Node.js/Express version
   > on a Java/Angular stack, built step by step with Claude Code.

   ## Tech stack

   - **Backend:** Java 21, Spring Boot 4, PostgreSQL, Flyway
   - **Frontend:** Angular 22, Angular Material
   - **Infrastructure:** Docker Compose, GitHub Actions

   ## Repository structure

```
   backend/    Spring Boot application
   frontend/   Angular application
   docs/       Architecture decisions and AI workflow notes
```
